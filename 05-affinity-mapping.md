\# Affinity Mapping





\## Purpose



Affinity Mapping was used to group similar research observations into categories, helping identify recurring user behaviors and design opportunities.





\## Themes





\### Trust \& Credibility



Users want confidence before contacting the company.





\### Portfolio Discovery



Users prefer exploring completed projects before making decisions.





\### Navigation



Users expect a simple and intuitive navigation structure.





\### Consultation



Users want an easy and transparent consultation process.





\### Information Clarity



Users need clear explanations of services and the company's value proposition.


Key UX Insights

## Insight 1: Build Trust Early

Users need stronger evidence before trusting the company. Trust indicators such as testimonials, completed projects, and client reviews should be visible early in the user journey.

---

## Insight 2: Showcase Completed Projects

Users rely on completed projects to evaluate the company's quality before contacting the business. The portfolio should be easy to find and explore.

---

## Insight 3: Guide Users to the Next Step

Users need a clear and obvious path to continue their journey. Strong call-to-action buttons and a simple consultation process can reduce friction.

---

## Insight 4: Communicate Value Immediately

Users should understand Rafters Interio's value proposition within the first few seconds of visiting the homepage.

---

## Insight 5: Support Confident Decision-Making

Clear navigation alone is not enough. Users also need detailed service information, project showcases, testimonials, and transparent communication to make confident decisions.
