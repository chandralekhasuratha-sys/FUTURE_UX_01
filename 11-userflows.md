Overview :



The User Flow was designed to map the complete journey a user takes while interacting with the Rafters Interior website. It focuses on creating a simple and intuitive navigation path that guides users from discovering the brand to booking a free consultation.



Objective :



Create a seamless navigation experience.

Minimize unnecessary user actions.

Guide users toward the primary call-to-action.

Improve overall usability.



Process :



The flow was created after analyzing user needs and the website structure. Each step was arranged to reduce friction and maintain a logical progression throughout the website.



Outcome :



The final user flow provides a clear journey that enables users to explore services, understand the company's expertise, and confidently book a consultation.
